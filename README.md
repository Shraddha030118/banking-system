# 🏦 Banking Management System (DBMS Project)

## 📌 Project Overview
The Banking Management System is a DBMS-based project designed to manage core banking operations such as customer management, accounts, transactions, loans, and employees. It demonstrates relational database concepts like tables, keys, joins, subqueries, stored procedures, and triggers.


## ⚙️ Technologies Used
- MySQL / SQL
- DBMS Concepts
- Relational Database Design


## 🗂️ Database Structure

### Tables Used:
- Customer
- Branch
- Account
- BankTransaction
- Loan
- Employee


## 🧾 Features

✔ Customer management  
✔ Account creation and tracking  
✔ Transaction handling (Deposit/Withdrawal)  
✔ Loan management system  
✔ Employee & branch details  
✔ SQL Joins and Aggregations  
✔ Subqueries  
✔ Stored Procedures  
✔ Triggers for data validation  

## 🧠 Key SQL Concepts Used

- Primary Key & Foreign Key
- INNER JOIN / LEFT JOIN
- GROUP BY & HAVING
- Subqueries
- Correlated Subqueries
- Stored Procedures
- Triggers
- Aggregate functions
